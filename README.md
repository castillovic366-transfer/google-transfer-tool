# Google Account Transfer Tool

This tool helps migrate files, emails, contacts, and photos between two Google accounts.  
It uses Google's official APIs and OAuth 2.0 for secure authorization.

## Features
- Transfer Google Drive files
- Migrate Gmail messages
- Sync Google Contacts
- Copy Google Photos albums
- Duplicate detection and cleanup
- One-click batch execution via .bat shortcut

## Requirements
- Python 3.10+
- Google Cloud project with OAuth credentials
- Published OAuth consent screen
